# Style reference sprite sheet (input)

Put the supplied Burhan pose sprite sheet(s) and/or the `COUSIN` avatar PNG here.
Every generator sends these to Gemini as a **style anchor** so all generated art
(Burhan, decoys, furniture, rooms, UI) shares one cohesive 8-bit look.

Any `.png` / `.jpg` in this folder is used. If empty, generation still runs but
style consistency relies on the text prompt alone.
