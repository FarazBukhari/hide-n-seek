# Burhan photos (input — not shipped)

Drop a few clear photos of Burhan here (`.jpg` / `.png`). They are used **only**
as references by `scripts/gen-assets/generate_burhan.py` to generate pixel-art
sprites that resemble him; they are never bundled into the game.

Tips for the best likeness:
- 2–4 photos: at least one clear, front-facing face shot.
- Good lighting, plain background if possible.
- A full-body shot helps with build/clothing.

These files are git-ignored (see `.gitignore`).
